# Evidence-led natal analysis

## 1. Blind audit

Before using biography, build an internal evidence table:

| Theme | Supporting factors | Constraints / counter-signals | Stability | Weight |
|---|---|---|---|---|

Start with:

- chart ruler: condition, house, aspects, and dispositor;
- Sun, Moon, Ascendant, MC, and angular planets;
- rulers of houses relevant to the user's question;
- repeated element/modality and house emphases;
- tight aspect clusters, configurations, and dispositorship chains;
- sect and major essential dignity/debility for classical planets.

Do not turn a single placement into a personality verdict.

## 2. Retrieval plan

Load references only for factors that survive prioritization:

1. planet file for the active function;
2. sign and house files for its mode and life arena;
3. aspect-type file and a pair-specific file when one exists;
4. condition, rulership, and tradition notes when they change the weighting;
5. synthesis pattern only after the underlying factors have been verified.

If no pair-specific module exists, combine the two planet functions with the aspect geometry; do not invent a missing canned interpretation.

## 3. Synthesis rules

- Repetition raises confidence only when signals are meaningfully independent.
- The same placement repeated in several report sections is one source, not several confirmations.
- Tight aspects and angularity usually matter more than isolated sign keywords.
- Dignity describes capacity/condition, not moral value or guaranteed outcomes.
- Outer planets become personal when angular, tightly aspecting personal planets, or strongly connected to the chart ruler.
- State the strongest counter-signal for every high-confidence claim.
- Translate configurations into ranges of manifestation rather than one biographical story.

## 4. Anti-Barnum check

Reject or rewrite a sentence when:

- it could apply to almost anyone;
- reversing its adjectives still sounds equally plausible;
- it lacks a cited placement, aspect, ruler, or repeated pattern;
- it presents both opposites without conditions;
- it uses the user's biography as the only evidence.

## 5. From audit to prose

For each major theme:

1. state the lived pattern in plain language;
2. cite two or more relevant chart factors when available;
3. explain a counter-signal or limiting condition;
4. give two or three plausible manifestations, with one primary form when evidence supports it;
5. end with an actionable implication rather than generic encouragement.

## 6. Coverage and report architecture

Before drafting a complete report, build a coverage map. Check each domain against the evidence matrix and mark it `substantial`, `supporting`, `weak`, or `not available`:

- personality and emotional regulation;
- thinking, communication, and learning;
- action, conflict, boundaries, and recovery;
- home, family, and private foundations;
- creativity, interests, friendship, and community;
- career, work systems, and public role;
- personal money, shared resources, and risk;
- relationships, intimacy, trust, and repair;
- solitude, unconscious patterns, rest, and spirituality;
- house axes and the functional role of each planet.

Write substantial domains in depth, combine supporting domains where that improves coherence, and state when a domain is weak or unavailable. Do not manufacture content to fill a heading. When the user asks for everything visible in the chart, completeness is measured by this coverage map plus the technical appendix, not by equal word counts.

Organize the interpretation from whole-chart architecture to life domains. Establish the chart ruler, dominant configurations, aspect networks, dispositor chains, sect, element/modality balance, and primary stabilizers before discussing personality or events. A planet-by-planet audit is a cross-check and appendix, not the main narrative.

## 7. Drafting and verification flow

1. Freeze the blind audit and evidence matrix before prose.
2. Write the scope-and-boundaries block once at the beginning.
3. Draft the thesis and executive summary from the highest-weight repeated signatures.
4. Draft each supported life domain using the claim chain: conclusion, evidence, constraint, manifestations, implication.
5. Run an internal traceability pass: every major claim must point to canonical chart data, and every high-weight configuration must appear somewhere in the report.
6. Run a contradiction pass: verify that counter-signals are explained by domain or condition rather than averaged into vague language.
7. Run a correction prompt after delivery: invite `confirmed / partly confirmed / contradicted / unknown` feedback for major claims. Record feedback without rewriting chart data.

If birth time is being checked against a Vedic rectification or another system, use the externally confirmed time only as input provenance. Recalculate the Western chart independently, compare time-sensitive Western factors across the justified interval, and report which factors remain stable. Do not import Vedic doctrine into Western interpretation or choose a time merely because it produces a preferred reading.
